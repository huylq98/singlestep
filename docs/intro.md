# Welcome

Welcome to the **Engineering Knowledge Base** — a practical, continuously growing resource for software engineers.

## What is this?

This site is designed to help you build strong mental models across key engineering domains. Each section focuses on implementation-oriented explanations rather than pure theory.

## How to use it

- Browse topics in the sidebar
- Use it as a reference during interview prep
- Revisit sections as you encounter concepts on the job
